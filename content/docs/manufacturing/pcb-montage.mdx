---
title: PCB Montage
description: Instructions for mounting the PCB in paperlesspaper hardware.
---

Using the display bonding fixture:

- Place the display upside down in the alignment jig.
- Make sure the display connector is facing the correct direction.
- Attach the pull tape.
- Apply two adhesive strips, leaving them slightly overhanging.
- Attach the PCB and press it down gently.
- Connect the display cable.
- The markings should be aligned in a straight line.
- Fold the connector lock down.

<Callout type="warn" title="Handle the display carefully">
  The display is fragile and can be damaged by excessive force or pressure.
  Handle it with care and avoid touching the display surface.
</Callout>

<Callout type="warn" title="Pull Tape placement">
  Pull tape from the display should not be at the same place as the Red corner
  of the display tape. It is important that the Pull Tape is glued to the end of
  the panel at the top and bottom. Because the panel gets pressure from the
  Passepartout it needs to be at the corner so the panel doesn't get bent.
</Callout>

<Callout type="warn" title="PCB stacking">
  PCBs with panels should not be stacked this high.
</Callout>
